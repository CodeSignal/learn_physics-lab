Physics Lab

Physics Lab is a configuration-driven 2D mechanics simulator. Each experiment uses the same rigid-body engine; only its JSON scene data changes.

Run an experiment

  1. Open an authored experiment configuration.
  2. Adjust only the parameters listed in the left panel.
  3. Select Run. Pause at any time, or Reset to return objects to their configured initial state while keeping your parameter choices.

What the display means

Distances are metres, time is seconds, mass is kilograms, and force is newtons. Positive x points right and positive y points upward. Blue/green/purple bodies are dynamic; grey and orange surfaces are fixed.

Rapier resolves contacts numerically, so friction and resting contact may differ slightly from idealized textbook examples.
