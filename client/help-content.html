Explore the simulation

Each experiment lets you observe how objects move and interact. Use the animation, measurements, and graph together to connect what you see with the physics you are learning.

Run, pause, and reset

  1. Select Run to begin. The elapsed-time display shows how long the experiment has been running.
  2. Select Pause to stop the motion and inspect a moment more closely. The same button becomes Resume when you are ready to continue.
  3. Select Reset to return the experiment to its starting position and try again.
  4. Select Center view if you want to bring the scene back into view.

Change a parameter

When an experiment offers adjustable parameters, use the controls in the left panel before running it. After you change a value, your earlier graph line stays visible so you can compare it with the next run. Select Clear comparisons to start a fresh set of graphs.

Read the results

The simulation shows the motion of the objects. The Live measurements panel reports values such as velocity, distance, or angular velocity as the experiment runs. The graph shows how a measurement changes over time.

Distances are measured in metres, time in seconds, mass in kilograms, and force in newtons. When axes are shown, positive x points right and positive y points upward.
